# PedigreeFes

A medical pedigree editor that follows the NSGC 2022 standard (interface in French).

**Open it:** https://clairevaltin.github.io/PedigreeFes/

## What it does

- **Draw family trees** by drag-and-drop, with right-click menus to add parents, partners, children and siblings
- **Standard symbols** – male, female, unknown sex, pregnancies, miscarriages, terminations, deceased, proband, heterozygous carriers
- **Several phenotypes** with a legend; a symbol is split into sectors when a person has more than one
- **Automatic layout** that keeps every generation aligned, with optional individual numbering (e.g. II-3)
- **Consanguinity** with the inbreeding coefficient (F)
- **Anonymise** a tree in one click before sharing it
- **Save, open, export and print**, with undo/redo and keyboard shortcuts for speed

Everything runs in your browser. Nothing is uploaded.

## How to use

Open the link above. Press **?** in the app for the full help and notation guide.
